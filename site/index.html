Help

Windows says “Windows protected your PC”

CalmMD isn't signed with a paid certificate yet. Click More info → Run anyway. Installing from the Microsoft Store or with winget avoids the message.

macOS says the app “can't be opened”

Right-click CalmMD in Applications and choose Open, then Open again. On recent macOS, use System Settings → Privacy & Security → Open Anyway. Installing with Homebrew avoids it: brew install --cask OWNER/calmmd/calmmd

Install from the terminal

Windows (PowerShell):

irm https://calmmd.app/install.ps1 | iex

macOS and Linux:

curl -fsSL https://calmmd.app/install.sh | sh

Both check the download against the release's published checksums before installing.

How do I sync my notes?

Keep your notes folder in Dropbox, iCloud Drive, OneDrive or Google Drive. CalmMD works with plain files and notices when they change on disk.

Does CalmMD collect anything?

No. There's no telemetry and no account. The only network request is activating a Supporter key, if you have one.
