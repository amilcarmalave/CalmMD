Code signing policy

Last updated: November 2026

How releases are built

Every CalmMD installer is built by GitHub Actions from the public source code in github.com/amilcarmalave/CalmMD, when a version tag is pushed. Nothing is built or signed on a personal computer. Each release lists SHA-256 checksums of its files (SHA256SUMS), and the install scripts check downloads against them.

What gets signed

Only CalmMD's own installers and program files, built from this repository. Third-party components are included unmodified from their upstream releases and listed in THIRD_PARTY_LICENSES.md.

Team and roles

  • Committers and reviewers: amilcarmalave (maintainer). Contributions from others are reviewed by the maintainer before they are merged.
  • Approvers: amilcarmalave. Every signing request is approved by hand, for each release.

All team members use multi-factor authentication on GitHub.

Privacy

CalmMD doesn't transfer any information to other networked systems unless the user asks for it, for example by opening a link or loading an image from the web. See the privacy policy.

Reporting a problem

If you think a signed CalmMD file was not built from this repository, or you've found a security problem, please report it privately on GitHub.
