# Welcome

This is a quiet place to write. Everything you type is **saved automatically**, so
there's nothing to remember.

## Getting around

- **File → Open Folder…** shows a folder in the sidebar. Click its name at the top of the
  sidebar to switch to another folder, a recent one, or the folder above it.
- Hover a file or folder and click the star to keep it in **Favorites**.
- **Spaces** (top of the sidebar) remember a folder, its tabs and the layout. Save one with
  **File → Spaces → Save Window as Space…** and switch between them with `Ctrl/Cmd+Alt+O`.
- The four views are at the bottom right: Source, Live, Split and Preview (`Ctrl/Cmd+E` cycles).
- The palette icon next to them changes the colour theme and the document style.

## Writing

- Use the toolbar, the menus, or select text for a small formatting bubble.
- Type `/` on an empty line to insert a heading, table, code block, diagram and more.
- `Ctrl/Cmd+Shift+P` finds any command. `Ctrl/Cmd+P` finds any file.

## Sharing

**File → Export** saves a PDF or a self-contained web page. With [Pandoc](https://pandoc.org)
installed, Word, OpenDocument and EPUB too.

> [!TIP]
> **Help → Markdown Guide** shows everything CalmMD can render.
